01  ·  The Concept
What Is a Package Relation?

General Tour is the main version of the trip. Deluxe Tour, Lower Antelope Canyon, Premier Antelope Canyon & Bend Adventure, and Affiliates are different ways of selling that same trip — a different price point, a different sales channel, a different set of extras. Even though guests book through five separate listings, they board the same vehicle, at the same time, with the same limited number of seats.

A package relation links these five listings into one family, with General Tour as the parent and the other four as its children. From that point on, every seat booked through any of the five is drawn from one shared total — not five independent ones.

One physical departure. Five ways to book it. One seat count.

02  ·  Why It Matters
Shared Capacity, Not Five Separate Counts

Without a relation, each of the five packages tracks its own bookings independently. If the vehicle for a departure holds 30 guests, and each listing is able to sell up to 30 seats on its own, that single departure could be sold several times over before anyone notices — guests would arrive to find there's no room left.

Linking the packages closes that gap. Every booking, through any of the five listings, draws down the same shared total for that departure time.

Example — 8:00 AM Departure
30 seats total
General Tour — 9 booked
Deluxe Tour — 6 booked
Lower Antelope Canyon — 4 booked
Premier / Bend Adventure — 5 booked
Affiliates — 3 booked
Remaining — 3 open seats

27 seats booked across five different listings, 3 seats still open — and every one of the five packages sees the same, correct, up-to-the-minute number.

03  ·  Preparation
Get Each Package Ready First

Every one of the five packages needs to exist on its own, fully set up, before any of them are linked together. Linking does not create or copy anything — it only tells the system to share seat counts between packages that already exist.

The rate for that version of the trip. Prices are never shared between linked packages — only the seat count is.

04  ·  The One Rule
Departure Times Must Match — Exactly

For the shared seat count to work, every package in the group must use the identical departure time for that slot. A difference of even a few minutes is enough to break the link — the packages will simply stop sharing seats, silently, with no error shown.

Correct — all five set to 8:00 AM
Incorrect — one package set to 8:05 AM

If General Tour runs more than once a day — say 8:00 AM and 1:00 PM — each departure time needs its own separate group of linked packages.

Group A
8:00 AM departure
All five packages linked together
Group B
1:00 PM departure
Its own, separate linked group

Two departure times, two independent families — sharing a package name doesn't share a seat count.

06  ·  Before You Go Live
Important Notes
This is set up per season
Linking these packages for 2027 does not carry over to 2028 or any other year. The same setup will need to be repeated for each future season.
The option may need to be switched on
If a package doesn't show any option to link relations at all, this feature may not be turned on for your account yet. Let your development team know and they'll check it.
Allow time for changes to take effect
After adding or changing a link, shared seat counts can take up to an hour to fully update everywhere. If it doesn't look right immediately, check back a bit later before assuming something's wrong.
Always use the official package relation option
Don't try to recreate this by any other means. The package relation option is the only place that checks for mistakes — like accidentally linking one package under two different parents.

Questions? Send a screenshot of what you're seeing to your development team, and we'll walk through it together.
